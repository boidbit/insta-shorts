🎬 Desi Toons Studio

Idea ya script likho → "Banao" dabao → GitHub pe Hindi cartoon reel banti hai (1080×1920, awaaz ke saath).

⚙️ GitHub connection (ek baar)
  1. Naya fine-grained token banao: Repository access → Only select repositories → insta-shorts.
  2. Permissions → Repository → Actions: Read and write, Contents: Read-only. Generate karke copy karo.
  3. Neeche paste karke "Save" dabao. Token sirf isi browser me save hota hai, repo me kabhi nahi jata.

Style: 2.5D me rasoi (kitchen), gali (gully / chai_tapri / kirana) aur chhat (terrace) gehrai wale sets ban jaate hain; baaki jagah normal dikhti hain.
🎭 Jagah aur characters khud chuno (optional)

Neeche ya to idea likho (AI inhi characters aur jagah ke saath script likhega), ya seedhe dialogue: har line Naam: baat, jaise Papa: Sarkari gaadi se aana!. Khali line = naya shot (na do to shot apne aap badalte hain). Devanagari likhne ki zarurat nahi.
